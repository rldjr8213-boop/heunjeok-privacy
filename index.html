흔적청소 개인정보처리방침

시행일: 2026년 11월 1일 · 앱 패키지: kr.local.privacyvault

인터넷 연결 없음광고 없음로그인 없음

1. 수집하는 개인정보

흔적청소는 어떤 개인정보도 수집하지 않습니다. 앱에는 인터넷 권한이 없어, 사진·문서·검사 결과를 포함한 어떤 정보도 개발자나 제3자에게 전송할 수 없습니다.

2. 기기 안에서 처리하는 정보

사용자가 허용한 사진과 문서를 휴대폰 안에서만 분석해, 주민등록번호·계좌번호·전화번호처럼 개인정보로 보이는 항목을 찾아 표시합니다. 검사 결과와 설정은 앱 전용 저장 공간에 암호화해 보관하며, 문서 원문은 저장하지 않습니다.

3. 사용하는 권한과 목적

  • 사진 접근: 갤러리 사진 속 개인정보 검사
  • 모든 파일 접근 (사용자가 직접 켠 경우에만): 기기 안 문서 검사, 사용자가 고른 문서와 중복 파일을 휴지통으로 이동
  • 알림: 검사 진행 상황 표시
  • 생체인증: 앱 잠금 해제 (선택)

4. 파일 삭제

사진과 문서 원본은 사용자가 직접 확인하고 선택한 경우에만 휴지통으로 옮기며, 자동으로 영구 삭제하지 않습니다. 휴지통의 파일은 Android 정책에 따라 일정 기간 뒤 완전히 지워집니다.

5. 보관 및 파기

앱의 "데이터 초기화" 기능을 쓰거나 앱을 삭제하면 앱이 저장한 모든 검사 기록이 지워집니다.

6. 제3자 제공 · 광고 · 분석 도구

없습니다. 흔적청소는 광고 SDK, 분석 도구, 외부 서버를 사용하지 않습니다.

7. 문의

Google Play 스토어의 흔적청소 앱 페이지에 있는 개발자 연락처로 문의해 주세요.

8. 변경

이 방침이 바뀌면 이 페이지에 변경 내용과 시행일을 게시합니다.
